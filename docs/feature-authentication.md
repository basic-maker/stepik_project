# Аутентификация пользователей

## Описание

Модуль аутентификации обеспечивает вход пользователей в систему с помощью электронной почты и пароля.

## Основные функции

- Регистрация нового пользователя
- Вход пользователя
- Восстановление пароля

## Пример использования

1. Пользователь вводит email и пароль.
2. Система проверяет учетные данные.
3. При успешной проверке пользователь получает доступ к защищенным разделам приложения.
